- ratings.csv — оценки пользователей (userId, movieId, rating, timestamp)

- tags.csv — теги (userId, movieId, tag, timestamp)
- users.txt — пользователи (разделитель |)
- occupation.txt — профессии
- genres.txt — жанры
- ratings_count.txt — мин. и макс. userId и количество их оценок
- sqlite.txt — версия SQLite и режимы вывода
